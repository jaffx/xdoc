# 笔记空间

这是第二个「空间」。每个空间是独立的文档根目录：

- 拥有自己的目录树（左侧会随空间切换）
- 拥有自己的 `xdoc.config.ts`，扩展互不影响
- 拥有自己的内置嵌入体之外的注册表

本空间注册了专属的 `:::quote`：

:::quote author="linus"
Talk is cheap. Show me the code.
:::

:::quote
没有署名时就不显示署名。
:::

内置嵌入体在这里同样可用：

:::tip 切换空间
点击左上角的空间名称可以切换回 examples 空间。
:::
