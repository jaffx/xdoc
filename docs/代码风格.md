# 代码风格

## TypeScript

| 项目 | 规范 |
| --- | --- |
| 严格模式 | `strict: true` |
| 模块 | ESM（`"type": "module"`） |
| 异步 | 优先 async/await，避免回调 |

## 命名

| 类型 | 风格 | 示例 |
| --- | --- | --- |
| 文件名 | kebab-case | `space-manager.ts` |
| 类名 | PascalCase | `SpaceManager` |
| 函数/变量 | camelCase | `listSpaces` |
| 常量 | UPPER_SNAKE_CASE | `MAX_RETRY` |

## 错误处理

```ts
// 明确错误类型
if (!runtime) throw new Error(`空间不存在：${id}`);

// 可选链 + 空值合并
const name = meta.name ?? 'default';
```

## 日志

```ts
console.log(`[xdoc] [${space.name}] 配置已重新加载`);
console.warn(`[xdoc] meta.json 写入失败：`, error);
console.error(`[xdoc] 启动失败：${error.message}`);
```
