# 测试指南

## 框架

使用 Node.js 内置的 `node:test`：

```ts
import { describe, it } from 'node:test';
import assert from 'node:assert';

describe('SpaceManager', () => {
  it('should create space', async () => {
    const manager = new SpaceManager(root, emit);
    const result = await manager.create({ name: 'test' });
    assert.strictEqual(result.space.name, 'test');
  });
});
```

## 运行测试

```bash
npm test              # 运行所有测试
npm test -- --watch   # 监听模式
```

## 测试结构

```
test/
├── core/         # 渲染核心测试
├── server/       # 服务端测试
└── mcp/          # MCP 测试
```

## 最佳实践

- 测试文件名：`xxx.test.ts`
- 每个 describe 对应一个模块/类
- 测试用例名称用英文，描述行为

## 注意

避免测试间的依赖，每个测试独立运行。
